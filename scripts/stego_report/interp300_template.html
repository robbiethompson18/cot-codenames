Can interpretability tools read the hidden word?

Partly. They do well above chance, and best when pointed at the fine-tuned model as it is about to answer. No tool beats a strong model simply reading the essay.

Same checkpoint as the first page: words300-n500 at step 50. Every number is how often a reader picks the secret from the essay's 8 candidates, where chance is 12.5%. Unless stated, each is 128 essays written by the trained sender (about ±4 points).

  • Reading the essay's tokens, the tools get 30–66%. The token lens and J-lens are weakest (30–38%). The NLA, oracle lens and activation oracle reach 62–66%, which sits between the 9B monitor (53%) and Haiku reading the text (73%).
  • Reading the fine-tuned model as it is about to answer, they get 76–80%. Here the model has read the essay and been asked for the word, with no candidate list shown. The same readouts on the original model get 25–66%.
  • Sonnet (85%) and Opus (88%) reading the text still do better than any tool. This sender mostly describes the word plainly, so there is little for a white-box tool to add.
  • On the essays the original model cannot decode, the tools tie Sonnet and trail Opus. Readouts on the fine-tuned model get 14–15; Sonnet gets 14 and Opus 17.
  • The fine-tuned model holds the word more often than it says it. Asked with no list it names the secret 14% of the time, usually giving a near-synonym, while the J-lens at that position picks the secret 80% of the time.
  • The tools were built for the original model and work unchanged on the fine-tuned one. On essay text the two give the same numbers; the fine-tune only shows up at the answer position.

Limits

  • One checkpoint, one run. Step 50 of a run where the sender was never pushed to hide from a reader with the same 8 candidates.
  • Layers were chosen on half the essays and scored on the other half. The tools' own layers (NLA 42, oracle lens 45, activation oracle 32) were fixed in advance.
  • The lenses score a word by its first token, so candidates that share a prefix, such as “surf” and “surfboard”, collide.
  • The hint-sentence picker was not checked for accuracy. It missed the hint in at least one essay shown above.
  • The oracle lens was run with a guessed placeholder token, not one confirmed against its authors' setup.
  • The open question's wording is ours and the model was never trained on it.
  • Haiku read the essay with two different prompts on the two pages: 73% here and 61% on the first page.
