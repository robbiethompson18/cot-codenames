How the sender hides the word

Each run settles on its own small vocabulary for each secret word. The hints are drifting from clues anyone could read toward keywords only that run's receiver has learned.

Sonnet 5.5 read 704 essays (64 from each of 11 settings) knowing the secret word, and labelled how each essay points to it and which phrases carry the hint. Everything here rests on those labels. There are 8 secret words, so a single word in a single setting is 3 to 14 essays.

  • What the monitor's penalty rewards depends on the referee. With no monitor the sender simply describes the object. With a lenient referee it switched to negation. Under the stricter referees it uses association: vocabulary from the word's world, worked into a normal essay.
  • Runs do not share a code. For the same secret, two runs' most-used hint words overlap by under 10%. One run's word for froth is "abundance", another's is "bubble", a third's is "airy".
  • Within a run the code is narrow. In the runs that learned against the 9B monitor, the same one keyword appears in about half to two thirds of a secret's essays. That is closer to a lookup table than to fresh hinting each time.
  • Some runs put the hint in the last sentence. In the soft-penalty run 72% of essays carry it only in the closing lines, in under two sentences. This morning's run spread it across six.
  • There are no letter tricks. Three essays in 704 were labelled wordplay and none structural. Acrostics only ever appeared in Qwen's reasoning, as plans it did not carry out.

Association: the word's vocabulary used as if it belonged ("natural luster" in a shoe-care essay for topaz). Description: the thing itself or its function, unnamed. Idiom: a stock phrase whose literal sense evokes the word ("steep learning curve" for hillside). Negation: saying what is absent or not needed.

What this means for the experiment

  • The private part of the code is the keyword choice. A reader who knows English gets the direct hints; only the run's own receiver has learned that "abundance" means froth. This fits the earlier result that the base 27B and other runs' receivers read some but not all of these essays.
  • It would not survive many words as it stands. A keyword per secret is a table. That matches the 300-word run collapsing: there is no keyword table for words seen once.
  • The monitor is beaten on the quiet essays, not on all of them. A stronger monitor mostly catches the louder ones, which is where further training pressure would go.
